# Q80 Pixel Camera 像素相機

啟動後會顯示後鏡頭取景。按綠色確認鍵或 `SNAP` 拍照並進入黑白列印預覽。在預覽頁可換版型、換演算法和調整深淺，所有設定都會套用到同一張照片。按綠鍵或 `PRINT` 列印，按橘色刪除鍵或 `RETAKE` 回到相機，按紅色取消鍵或 `EXIT` 離開。

觸控按鈕比照實體數字鍵以三欄排列。第三排右欄顯示當前閾值或網點深淺，最下排為退出、重拍及拍照／列印。

| 按鍵 | 操作 |
| --- | --- |
| 1 | 依序切換 SHADE、CLUSTER、BOLD，預設使用 SHADE。 |
| 2 | 切換 WIDE 橫幅和 TALL 直幅。WIDE 為 384×288 點。TALL 旋轉同一畫面，沿走紙方向延伸至 384×512 點，保留整張畫面。兩種都使用 384 點紙寬。 |
| 3 | 開關 FACE 逆光補償。用軟體提亮畫面中央的暗部，彩色取景和黑白列印預覽都會套用。 |
| 4 / 6 | 調淡／調深，每次調整 8，範圍 −64 到 +64。BOLD 調整自動閾值，SHADE 和 CLUSTER 調整網點深淺。 |
| 5 | 在 2×2、3×3 和 4×4 網點之間切換。SHADE 與 CLUSTER 使用此設定，預設為 3×3。 |
| 7 | 切換印表機濃度 1、3、4，預設為 4。此設定影響紙上黑度，螢幕點陣維持相同。 |
| 8 | 每按一次送出 96 點的空白紙，方便撕下照片。也可點畫面上的 FEED。 |

| 轉圖模式 | 原理 |
| --- | --- |
| SHADE | 每個小格用平均亮度決定黑點數，依固定順序擺點。3×3 選項沿用原本的網點排列。 |
| CLUSTER | 同樣以小格取樣，但黑點以相連方式擴張，供實際試印比較。 |
| BOLD | 用全圖直方圖選擇黑白閾值。適合輪廓、文字或高對比場景。 |

SHADE 和 CLUSTER 都屬於有序網點，會自動提亮偏暗的照片，再套用手動調整。兩者使用固定的小格點序。原先在這台 Q80 上試過 Floyd–Steinberg 與 Atkinson 誤差擴散，紙上的散點較明顯，輪廓也較難辨認。藍噪聲有序抖動是另一種點陣設計，這版沒有加入。參考 [Ulichney 的有序抖動研究](https://cv.ulichney.com/papers/1994-filter-design.pdf)。

列印和拍照後的黑白預覽使用同一份點陣。完整預覽會存成裝置上的 `/data/app/pixel_camera/latest_pixel.png`。切換轉圖設定時會重新處理記憶體中的灰階照片。較長的直幅分批送到印表機。

這台 Q80 的相機以 640×480 擷取。彩色取景縮放為 480×360。拍照後保留完整的 640×480 灰階圖，產生列印點陣時以面積平均直接縮成 384×288 橫幅，或同時旋轉和縮成 384×512 直幅。兩種版型都保留完整畫面。黑白預覽以 1:1 顯示列印點陣。彩色取景、照片預覽和列印都會修正相機輸出的左右鏡像。若軟體取景失敗，會回到原廠取景並顯示 `NATIVE LIVE`，拍照結果仍會修正左右方向。

XUI、OSAL 和 V4L2 提供相機操作介面。這台 Q80 的相機驅動未回報可用的點測光、白平衡或曝光鎖定。FACE 處理已擷取的影像，將補光強度集中於畫面中央，越靠近邊緣越弱，並保留純黑和純白。

```powershell
python -m q80 app build pixel_camera
python -m q80 app deploy pixel_camera
python -m q80 app run pixel_camera
```
